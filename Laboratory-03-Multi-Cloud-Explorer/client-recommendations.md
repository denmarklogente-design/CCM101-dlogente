# Cloud Platform Recommendation Challenge

## Client A – Startup Company

### Recommended Platform: AWS

For a startup with a small budget, AWS can be a practical option because the company can start with only the resources it currently needs. As the mobile application gains more users, additional cloud resources can be added without having to build a large physical infrastructure from the beginning. AWS also has services that can support application hosting, databases, and file storage.

### Possible Services

* `Amazon EC2`
* `Amazon S3`
* `Amazon RDS`

---

## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure would fit the university well because its existing environment already depends on Microsoft technologies. Using Azure can make it easier to connect cloud services with systems such as Windows Server, Microsoft 365, and Active Directory. The university can gradually move selected workloads while keeping its existing Microsoft-based setup.

### Possible Services

* `Azure Virtual Machines`
* `Microsoft Entra ID`
* `Azure Blob Storage`

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform

Google Cloud Platform is a suitable option for an organization focused on AI research because it provides services designed for machine learning and data-intensive workloads. The company could use Compute Engine for virtual computing, Vertex AI for developing and managing machine learning projects, and GKE for applications that require containers.

### Possible Services

* `Compute Engine`
* `Vertex AI`
* `Google Kubernetes Engine (GKE)`

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS would be a strong choice for a global online store because e-commerce systems may experience sudden changes in traffic during promotions, holidays, or major sales. Its computing, load balancing, and storage services can work together to support an application that needs to serve many users. This can also help the company expand its online services as its customer base grows.

### Possible Services

* `Amazon EC2`
* `Elastic Load Balancing`
* `Amazon S3`

# Multi-Cloud Decision Matrix

| Business Requirement    | Recommended Platform | Justification                                                                    |
| ----------------------- | -------------------- | -------------------------------------------------------------------------------- |
| Startup Company         | AWS                  | Flexible services that can support gradual business growth                       |
| Enterprise Organization | AWS                  | Extensive cloud services for different business workloads                        |
| Microsoft Environment   | Azure                | Works well with existing Microsoft technologies                                  |
| AI / Machine Learning   | GCP                  | Provides specialized services for AI and machine learning                        |
| Kubernetes Deployment   | GCP                  | Offers managed Kubernetes through GKE                                            |
