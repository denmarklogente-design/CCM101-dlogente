# Cloud Platform Comparison

## AWS vs Microsoft Azure vs Google Cloud Platform

| Category            | AWS                                          | Microsoft Azure                            | Google Cloud Platform              |
| ------------------- | -------------------------------------------- | ------------------------------------------ | ---------------------------------- |
| Launch Year         | 2006                                         | 2010                                       | 2008                               |
| Compute Service     | `Amazon EC2`                                 | `Azure Virtual Machines`                   | `Compute Engine`                   |
| Storage Service     | `Amazon S3`                                  | `Azure Blob Storage`                       | `Cloud Storage`                    |
| Networking Service  | `Amazon VPC`                                 | `Azure Virtual Network`                    | `VPC`                              |
| Identity Service    | `AWS IAM`                                    | `Microsoft Entra ID`                       | `Cloud IAM`                        |
| Primary Strength    | Large selection of cloud solutions           | Microsoft ecosystem compatibility          | AI, analytics, and containers      |
| Ideal Organizations | Businesses with different cloud requirements | Organizations using Microsoft technologies | Data and AI-oriented organizations |

## Analysis

### 1. Which cloud provider offers the broadest range of services?

Among the three platforms, I would consider AWS as the provider with the widest selection of services. It covers many areas of cloud computing, so organizations can choose services depending on whether they need computing, databases, storage, networking, security, or other solutions.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure would be the better option for an organization that already uses Microsoft products. Its cloud services can work alongside technologies such as Windows Server, Microsoft 365, and Microsoft identity solutions, which can make the transition to cloud services more convenient.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong option for projects that focus on artificial intelligence, machine learning, and Kubernetes. Services such as Vertex AI and Google Kubernetes Engine provide tools for developing AI applications and managing containerized workloads.

### 4. Which cloud platform would you personally choose and why?

If I were given the opportunity to select one platform, I would choose Google Cloud because I am interested in technologies involving data, AI, and modern application development. Its services for machine learning and Kubernetes would also give me useful tools to explore while developing technical skills.
