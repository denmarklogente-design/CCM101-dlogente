# Microsoft Azure

## Brief Overview

Microsoft Azure is a cloud platform developed by Microsoft that provides different online services for computing, storage, networking, security, and application development. It can support both Windows and Linux systems, making it useful for organizations with different types of workloads.

## Global Infrastructure

Azure operates through a worldwide network of cloud regions and data centers. Organizations can select an appropriate region depending on where their users are located, where their data needs to be stored, and what availability requirements their applications have.

Having cloud locations in different areas also allows businesses to deploy applications closer to their customers and create systems that can operate across multiple locations.

## Cloud Management Console

The Azure portal is a web-based interface where users can manage their Azure environment. From the portal, administrators can create and configure virtual machines, storage, networks, identities, and other cloud resources.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide virtual computing environments that can be configured with different operating systems and resources. They can be used to host applications, websites, development environments, and other workloads.

### 2. Azure Blob Storage

Azure Blob Storage is used to keep large amounts of object-based data. It can store items such as documents, photos, videos, backups, and application data.

### 3. Azure Virtual Network

Azure Virtual Network allows cloud resources to communicate within a controlled network environment. It provides options for configuring network addresses, subnets, routing, and connections between resources.

### 4. Microsoft Entra ID

Microsoft Entra ID provides identity and access management for cloud resources and applications. It helps organizations manage user accounts and determine which resources users or applications are allowed to access.

## Three Advantages

### 1. Microsoft Ecosystem Compatibility

One advantage of Azure is its connection with other Microsoft technologies. Organizations already familiar with Microsoft products can use Azure alongside their existing systems.

### 2. Support for Different Workloads

Azure can host both Windows and Linux workloads. This gives organizations more flexibility when selecting the operating systems and applications they want to use in the cloud.

### 3. Global Cloud Presence

Azure has cloud infrastructure available across many geographic locations. This gives organizations more choices when deciding where to deploy their applications and store their data.

## Typical Enterprise Use Cases

Azure can be used by businesses for application hosting, data storage, virtual machines, networking, identity management, and backup services. For example, an organization can use Azure Virtual Machines to run its applications, Blob Storage to keep files and backups, and Microsoft Entra ID to manage employee access.

It can also be useful for companies that want to move some of their existing infrastructure to the cloud while continuing to use Microsoft-based technologies.
