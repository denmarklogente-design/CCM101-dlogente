# Security Audit Report

## Principle of Least Privilege (PoLP)

The Principle of Least Privilege means providing users and services with only the permissions necessary for their responsibilities. Limiting access in this way helps prevent unnecessary privileges and reduces the possible impact of compromised accounts or services.

## Attack Surface

An attack surface includes the interfaces and services that could be targeted to gain access to a system. Examples on a virtual machine include network ports, active applications, and user accounts. Reviewing these areas helps administrators identify potential security weaknesses.

## Default Deny Policy

A Default Deny policy blocks incoming connections unless a firewall rule specifically permits them. This approach limits access to approved services instead of allowing connections by default, helping reduce unwanted network exposure.
