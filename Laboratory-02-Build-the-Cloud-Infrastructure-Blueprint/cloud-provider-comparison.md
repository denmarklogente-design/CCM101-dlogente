# Cloud Provider Comparison

## Infrastructure Service Comparison

| Infrastructure Component       | AWS        | Microsoft Azure        | Google Cloud Platform       |
| ------------------------------ | ---------- | ---------------------- | --------------------------- |
| Compute                        | Amazon EC2 | Azure Virtual Machines | Compute Engine              |
| Storage                        | Amazon S3  | Azure Blob Storage     | Cloud Storage               |
| Networking                     | Amazon VPC | Azure Virtual Network  | Virtual Private Cloud (VPC) |
| Identity and Access Management | AWS IAM    | Microsoft Entra ID     | Cloud IAM                   |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

I would consider **AWS** to have the broadest selection of cloud services. It provides different solutions for computing, storage, databases, networking, security, and application development. Because of this variety, organizations can choose services based on their specific project requirements.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend **Microsoft Azure** for an organization that mainly uses Microsoft products. Azure works closely with Microsoft's existing technologies, which can make it easier to connect current systems and applications to cloud services.

### 3. Which platform is widely recognized for Artificial Intelligence, Machine Learning, and Kubernetes services?

I would choose **Google Cloud Platform** because it is known for its capabilities in Artificial Intelligence and Machine Learning. It also provides Kubernetes services that support the deployment and management of containerized applications.

### 4. What similarities did you observe among the three cloud providers?

I noticed that **AWS, Microsoft Azure, and Google Cloud Platform** provide many of the same fundamental cloud services. All three offer resources for computing, storage, networking, and identity management. Their names, tools, and features may differ, but they serve similar purposes in building and managing cloud-based systems.
