
## Mission Overview

This laboratory explores how Bash scripting and Cron can automate routine cloud administration tasks. The activity involves creating a backup script to compress application data and setting up a schedule for recurring execution.

## Objectives

- Learn the basic concepts of Bash scripting and variables.
- Develop and run a script for backing up application data.
- Apply executable permissions using `chmod`.
- Schedule automated tasks with Cron.
- Record the procedures and results in Markdown documentation.

## Commands Executed

The following commands and utilities are used during the activity:

- `mkdir` – creates directories.
- `echo` – writes text to a file or displays a message.
- `nano` – opens a terminal-based text editor.
- `chmod +x` – grants executable permission to a script.
- `tar -czf` – creates a gzip-compressed archive.
- `ls -l` – displays files and their permissions.
- `crontab -e` – edits scheduled Cron tasks.
- `crontab -l` – displays the current user's Cron entries.

## Skills Learned

- Writing and executing Bash scripts.
- Managing Linux file permissions.
- Creating compressed backup archives.
- Scheduling recurring tasks using Cron.
- Preparing technical documentation with Markdown.
