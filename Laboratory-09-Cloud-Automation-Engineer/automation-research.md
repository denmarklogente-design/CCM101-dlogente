# Automation Research

## Bash Scripting

Bash scripting allows users to combine Linux commands in a single file and execute them in sequence. The `#!/bin/bash` line, known as the shebang, indicates that Bash should interpret the commands in the script.

## Variables

Variables hold values that can be reused throughout a script. For example, `$BACKUP_DIR` stores the location of the backup folder. Using variables makes the script easier to manage because the same directory path does not need to be typed repeatedly.

## Cron Jobs

Cron is a Linux utility that schedules commands or scripts to run at specific times. It helps automate recurring tasks, such as creating backups, so they can run according to a schedule without requiring manual execution each time.
