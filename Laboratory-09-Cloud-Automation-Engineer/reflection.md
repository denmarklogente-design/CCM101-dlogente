# Mission Reflection

This laboratory activity helped me understand how automation can make cloud administration easier and more efficient. I learned how to create a Bash script that prepares a backup directory and compresses application data into a timestamped archive. I also learned that the `chmod +x` command allows a script to run directly when the required permissions are available.

Automation is useful when managing multiple cloud servers because it reduces repetitive tasks and helps prevent manual errors. However, scripts must be handled carefully because incorrect commands or file paths can affect important data. Testing scripts before scheduling them is important to make sure they work as expected.

I also learned the difference between Bash scripting and Docker Compose YAML from Mission 6. Bash scripts execute commands to perform tasks, while Docker Compose uses YAML configuration to define services and containers. Both tools help simplify cloud administration, but they are used for different purposes.

Throughout Laboratories 1 to 9, I gained knowledge about cloud computing, including infrastructure, cloud services, containers, data management, deployment, operations, security, and automation. These activities helped me understand that managing cloud resources involves more than setting up servers. It also requires proper security, monitoring, and maintenance.

The cloud role I enjoyed most was the **Cloud Automation Engineer** because I learned how scripts and scheduled tasks can reduce manual work and make routine operations more consistent. I also realized that automation requires careful planning, testing, and verification to avoid errors.

Overall, this laboratory showed me that automation is an important part of cloud computing. When implemented correctly, it can improve efficiency and reliability while reducing the effort needed to manage recurring tasks.
