# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory activity focused on cloud storage and object storage. I compared Block Storage, File Storage, and Object Storage to understand their different purposes and uses. I also deployed MinIO using Docker in the KillerCoda Ubuntu Playground. After deploying MinIO, I accessed the Web Console, created a bucket named `client-photos`, and uploaded a sample file.

## Objectives

- Understand the differences between Block Storage, File Storage, and Object Storage.
- Identify the appropriate use of different cloud storage types.
- Deploy MinIO using Docker.
- Configure MinIO using environment variables.
- Access the MinIO Web Console through port `9001`.
- Create an object storage bucket.
- Upload a sample object to the bucket.
- Practice Linux and Docker commands.
- Document the laboratory activity using Markdown and GitHub.

## Tools Used

- KillerCoda Ubuntu Playground
- Ubuntu Linux
- Docker
- MinIO
- GitHub
- Web Browser
- Markdown

## Skills Learned

Through this activity, I learned how different cloud storage types are used for different purposes. I also learned how to deploy MinIO using Docker and configure the container using environment variables.

I practiced Docker commands such as `docker pull`, `docker run`, and `docker ps`. I learned how to map container ports and access the MinIO Web Console through port `9001`.

I also learned how to create a bucket and upload an object using the MinIO Web Console. This activity helped me improve my Linux command-line skills and my ability to document and organize cloud computing activities using GitHub.
