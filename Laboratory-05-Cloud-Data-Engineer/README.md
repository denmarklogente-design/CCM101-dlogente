# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory activity introduced the basic concepts and practical use of cloud storage. I compared Block Storage, File Storage, and Object Storage and then applied the concepts by deploying MinIO through Docker. I accessed the MinIO Web Console, created a storage bucket, and uploaded a sample object.

## Objectives

- Identify the differences between Block, File, and Object Storage.
- Understand the common uses of different cloud storage types.
- Deploy MinIO using Docker.
- Configure MinIO using environment variables.
- Access the MinIO Web Console through port 9001.
- Create an object storage bucket.
- Upload a sample object to the bucket.
- Practice basic Linux and Docker commands.
- Document the deployment process in GitHub.

## Tools Used

- KillerCoda
- Ubuntu Linux
- Docker
- MinIO Object Storage
- GitHub
- Web Browser
- Markdown

## Skills Learned

This activity helped me understand the purpose of different cloud storage types and when they can be used. I also learned how to deploy an object storage service using Docker and configure its administrator credentials using environment variables.

I practiced using Docker commands such as `docker pull`, `docker run`, and `docker ps`. I also learned how to expose container ports and access a service through a web browser.

Using the MinIO Web Console gave me experience in creating a bucket and uploading an object. I also improved my documentation and GitHub organization skills by recording the technical steps and evidence of the activity.
